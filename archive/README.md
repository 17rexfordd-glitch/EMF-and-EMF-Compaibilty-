# Archived compatibility attempts

FIX1 through FIX5 were intermediate compatibility/repackaging attempts made before switching to the safer strategy of patching EMF 3.3.5 itself.

They are intentionally not the current install target.

The current supported strategy is the release built from `tools/build_bridge.py` and published by the GitHub Actions workflow.

Historical local artifact names were:

- `EMF-Compat-Combined-1.21.1-NeoForge-EMF3.3.5-FIX1.jar`
- `EMF-Compat-Individual-Fixes-1.21.1-EMF3.3.5-FIX1.zip`
- `EMF-Compat-EMF3.3.5-FIX2-DROP-IN-REPLACEMENTS.zip`
- `EMF-Compat-EMF3.3.5-FIX3-5-JARS.zip`
- `EMF-Compat-EMF3.3.5-FIX4-AUTO-INSTALL.zip`
- `EMF-Compat-EMF3.3.5-FIX5-VERIFIED-INSTALL.zip`

Those attempts are documented here so the version history is not lost, but the bridge release supersedes them.
