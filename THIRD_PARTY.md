# Third-party projects and attribution

## Entity Model Features (EMF)

Upstream: https://github.com/Traben-0/Entity_Model_Features

This project patches and redistributes Entity Model Features 3.3.5. Upstream EMF is licensed under LGPL-3.0-or-later. The release workflow downloads the exact upstream license and publishes it beside the patched JAR.

The compatibility bridge source in this repository is intended to be distributed under the same LGPL terms as the modified EMF library.

## EMF Compatibility

Upstream: https://github.com/victorkozhokin/emf-compat

The compatibility behavior and current API targets were checked against the public emf-compat source for Minecraft 1.21.1 / NeoForge. This repository is not the official emf-compat project.

## Important

No ownership of either upstream project is claimed. This repository exists to preserve compatibility for a specific Minecraft 1.21.1 + NeoForge 21.1.248 modpack configuration.
